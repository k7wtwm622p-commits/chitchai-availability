# Chit Chai 空き状況の自動確認

有料AI・有料APIを使わず、GitHub Actions の公開リポジトリ用の標準 Ubuntu ランナーで、公開予約画面を読み取るプログラムです。GitHub のクラウド実行での初回確認はまだ完了していません。

## 無料で動かす条件

- この専用リポジトリを **Public** にします。既存の顧客管理アプリを公開しないでください。
- 標準 `ubuntu-latest` を使用します。プライベートリポジトリではジョブを実行しない設定です。
- 有料API・AIサービス・プロキシ・カード登録は不要です。Actions のキャッシュや成果物アップロードも使いません。
- 日本時間11:02〜22:52、約10分おきに実行します。GitHubの混雑で遅延・実行漏れが起こるため、リアルタイム保証はありません。
- 公開されるのはコード、スタッフ名、予約可能時刻です。顧客情報・パスワード・予約台帳は取得しません。

## 確認条件

来店履歴は「ある」。指名なし、三嶋、宮原、鈴木を個別に確認します。タイ古式65／95／125分（予約枠80／110／140分）を1コースずつ選び、日時選択画面の有効な時刻ボタンを読み取ります。時刻の選択や予約の確定は行いません。

本日から順に最大8日を確認し、最初に予約できる日の時刻を出力します。読み込みエラー・制限画面・未確認の枠は `error`、完了した空きなし表示のみ `none` とします。CAPTCHAやアクセス制限を検出したら停止し、回避はしません。

## 初回設定

1. 新しい Public リポジトリを作り、README を付けて main ブランチを初期化します。
2. このディレクトリの内容をそのリポジトリのルートへ配置します。
3. Actions からこのワークフローを1回実行し、結果とログを確認します。
4. `data/availability.json` が実際に更新されたら、その raw URL を表示ページのデータ取得先へ設定します。
5. 全12条件の照合と、取得失敗・情報が古い場合の表示を確認してからお客様へURLを案内します。

GitHub の仕様や予約画面の変更で止まることがあります。Actions の実行履歴と表示ページの最終確認時刻で確認してください。公開リポジトリの定期実行は長期に活動がないと停止することもあります。

参考: https://docs.github.com/en/billing/concepts/product-billing/github-actions

## ローカルでの確認

Node.js 22以降で `npm ci`、`npm test`。ブラウザーでの実動作確認は `npx playwright install --with-deps chromium` の後に `npm run collect` で行います。顧客用サイトの構造が変わった場合は、公開画面での確認後にセレクターを修正してください。
